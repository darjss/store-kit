# Admin mobile redesign brief

Approved direction: mobile-first, Mongolian-first retail operations for a store owner working from a phone under bright shop lighting.

- Selected probe: `../probes/admin-retail-ledger.png`
- Reference lane: Shopify Mobile × Square workflow clarity without visual copying
- Restrained light palette with a flat burnt-orange accent
- Edge-to-edge mobile records with 44–48px touch targets and labeled bottom navigation
- Dedicated mobile product and order summaries; full tables only on desktop
- Essential product fields first; advanced fields behind progressive disclosure
- Dashboard prioritizes actionable work and store readiness
- Remove forced dark mode, purple, decorative icons, technical copy, and generic card grids
- Preserve all real auth, CRUD, media, conflict, loading, error, and destructive behavior
